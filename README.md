# Khanh Duy's Portfolio Website

A modern, responsive portfolio website showcasing my projects, skills, and experience as a Full Stack Developer and Open Source Contributor.

## ✨ Features

- **Responsive Design**: Works seamlessly on desktop, tablet, and mobile devices
- **Dark/Light Theme**: Toggle between dark and light themes with preference persistence
- **Smooth Animations**: Elegant transitions and animations throughout the site
- **Interactive Navigation**: Smooth scrolling and active link highlighting
- **Project Showcase**: Display of featured projects from GitHub
- **Skills Section**: Categorized list of programming languages and technologies
- **Contact Information**: Easy ways to connect

## 🛠️ Technologies Used

- **HTML5**: Semantic markup
- **CSS3**: Modern styling with CSS variables and Grid/Flexbox
- **JavaScript (Vanilla)**: For interactivity and theme switching
- **Font Awesome**: Icon library
- **Google Fonts**: Typography

## 📁 Project Structure

```
├── index.html          # Main HTML file
├── styles.css          # Styling with CSS variables and responsive design
├── script.js           # JavaScript for interactivity
└── README.md           # This file
```

## 🚀 Quick Start

1. Clone the repository
```bash
git clone https://github.com/khanhduy1407/khanhduy1407.github.io.git
```

2. Open `index.html` in your browser or use a local server:
```bash
python -m http.server 8000
# or
node http-server
```

3. Visit `http://localhost:8000` in your browser

## 📝 Customization

### Update Personal Information
1. Edit email in the contact section
2. Update social media links
3. Modify project descriptions and links

### Color Scheme
Edit the CSS variables in `styles.css`:
```css
:root {
    --primary-color: #3b82f6;     /* Change to your preferred color */
    --secondary-color: #1e40af;
    /* ... other variables ... */
}
```
